QUEST 01

당당한 헛소리 할루시네이션 방어

  • AI는 정답 자판기가 아닌 확률적 문장 생성기임을 인지할 것
  • 숫자, 날짜, 전문 지식은 교재나 공식 자료로 이중 교차 검증 필수
  • AI 산출물은 완성본이 아닌 수정이 필요한 초안으로만 취급
QUEST 02

아차 하면 터지는 저작권 지뢰 피하기

  • 인간의 창작성이 없는 AI 산출물은 원칙적으로 저작권 불인정
  • 기존 작품의 스타일이나 캐릭터를 똑같이 베껴 달라는 프롬프트 입력 절대 금지
  • 타인의 그림이나 글을 무단으로 학습 데이터에 넣는 행위 주의
QUEST 03

내 데이터는 내가 지키는 개인정보 보안

  • 채팅창에 입력한 데이터는 AI의 학습 재료로 영구 저장될 위험 존재
  • 연락처, 비밀번호, 사적인 고민 등 민감 정보 입력 절대 금지
  • 설정 메뉴에서 대화 이력 및 학습 기능 비활성화 권장
QUEST 04

꼼수 대신 당당한 출처 표기와 투명성

  • 과제 시작 전 교수님과 학교의 AI 활용 지침 사전 확인 필수
  • 외부 공유 시 사람이 인식할 수 있는 가시적 워터마크/표시
  • 활용한 AI 모델 이름, 사용 일자, 프롬프트 내용 명확히 기재
