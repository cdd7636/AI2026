Core Features

4대 핵심 기능 상세 명세

사용자 편의성과 정밀한 공간데이터 처리를 조합한 주요 구현 요구사항입니다.

Feature 01

지도 마커 & 스쿨존 레이어 토글

어린이집의 위경도 좌표를 기반으로 지도상에 직관적인 노란색 커스텀 마커를 표시하고, 스쿨존 반경 레이어를 토글 방식으로 손쉽게 제어합니다.

  • 위도/경도 데이터 기반 기본 **노란색 마커** 배치
  • 지도 우측 상단 **Toggle Switch**를 통한 레이어 제어
  • 스쿨존 300m 보호구역 시각적 반경 렌더링
Feature 02

CCTV 반경 연산 & 안전도 등급

어린이집 중심 반경 300m 내에 존재하는 총 CCTV 설치 대수를 하버사인(Haversine) 공식을 적용하여 정밀하게 합산하고 마커 테두리 색상으로 등급을 표현합니다.

  • **상 (High)**: CCTV 10대 이상 (#10B981)
  • **중 (Medium)**: CCTV 5대 ~ 9대 (#F59E0B)
  • **하 (Low)**: CCTV 5대 미만 (#EF4444)
Feature 03

사이드바 필터링 & 통계 요약

실시간 키워드 검색, 통학차량 운영 여부, CCTV 10대 이상 보유 여부 필터를 제공하며 데이터 통계를 한눈에 볼 수 있는 요약 카드를 배치합니다.

  • 통학차량 운영 여부 (전체 / Y / N) 필터
  • CCTV 10대 이상 보유 시설만 보기 토글 스위치
  • 어린이집명 및 도로명/지번 주소 실시간 실시간 검색
Feature 04

마커 클릭 상세 정보 팝업

지도 상의 특정 어린이집 마커 클릭 시 해당 시설의 안전 관련 핵심 정보(소방 점검, 비상구, 통학차량 등)를 카드 모달로 띄워줍니다.

  • 어린이집명 및 주소(도로명/지번) 표시
  • 비상구 설치 여부 & 소방점검일자 (YYYY-MM-DD)
  • 반경 300m CCTV 수 및 안전도 등급 배지 표시
Interactive Logic Simulator

안전도 등급 판정 시뮬레이터

PRD의 안전도 산출 로직을 직접 테스트해보세요. 반경 300m 이내 CCTV 개수를 조절하면 실시간으로 마커 테두리 색상과 안전 등급 배지가 변경됩니다.

Haversine 거리 연산 로직

$a = \sin^2(\Delta\phi/2) + \cos\phi_1 \cdot \cos\phi_2 \cdot \sin^2(\Delta\lambda/2)$
$d = 2 \cdot R \cdot \arcsin(\sqrt{a})$ ($R = 6371\text{km}$)
이 계산식을 통해 어린이집 좌표와 스쿨존 CCTV 좌표 간 직선 거리가 300m 이하인 CCTV 개수를 실시간 합산합니다.

01

원시 데이터 필터링

• 통학차량운영여부 (Y/N)
• 비상구설치여부 정율화

02

300m 하버사인 공간 연산

각 어린이집 좌표(Lat/Lng) 기준으로 반경 300m 이내에 위치한 스쿨존 CCTV 시설의 총 카메라 개수를 계산 합산

• Haversine Distance Calc
• Radius threshold: 0.3km
• Safety Grade Assignment
03

웹 경량 데이터 JSON 변환

# PRD: 전국 어린이집 안전도 및 스쿨존 지도 서비스

1. 프로젝트 개요

본 프로젝트는 `전국어린이집표준데이터.csv` 및 `전국어린이보호구역표준데이터.csv`를 기반으로, 전국 어린이집의 위치와 반경 300m 내 CCTV 설치 현황을 분석하여 안전도 등급을 시각화하고, 보호구역(스쿨존) 영역을 확인할 수 있는 웹 지도 애플리케이션을 제공합니다.

2. 주요 기능 및 요구사항
  • 지도 마커 및 스쿨존 레이어 토글: 노란색 기본 마커, 우측 상단 레이어 ON/OFF 토글
  • CCTV 반경 연산 및 안전도 등급: Haversine 300m 이내 합산 (상: 10대+, 중: 5~9대, 하: 5대 미만)
  • 사이드바 필터링 & 검색: 통학차량 여부, CCTV 10대 이상, 실시간 검색, 요약 통계 카드
  • 마커 클릭 상세 팝업: 어린이집명, 주소, 비상구, 소방점검일자, CCTV 수, 통학차량 여부
